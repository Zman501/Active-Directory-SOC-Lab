# Active-Directory-SOC-Lab

## Objectives

This Active Directory SOC Lab project can be used to help you make an isolated environment for emulating as well as detecting common cyber attacks used by real world adversaries. The main goals of this lab are to gather logs to analyze them in a SIEM system and to gain a better understanding of how Active Directory works. While the scale of this lab is relatively small, it can still be applied to the real world in Small and Medium-sized Businesses (SMBs) as well as enterprise infrastructure.

### Skills To Gain With This Project

- Gaining a better understanding of SIEM concepts and how to use those concepts practically.
- Analyze and interpret network logs more effectively.
- Be able to generate and recognize attack patterns.
- Knowledge of common security vulnerabilties and network protocols.
- Critical thinking and problem solving skills that can be applied in cybersecurity.

### Tools Used

- Splunk for log ingestion and analysis.
- Nmap for network reconnaisance.
- Atomic Red Team for telemetry generation to create realistic network traffic and attack signatures.
